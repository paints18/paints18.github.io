# Privacy Policy — Bomb Party

**Last updated: 2026-06-12**

This Privacy Policy explains what data Bomb Party ("the bot", "we") collects when you use it on Discord, how it is used, and how you can request its deletion.

## Data We Collect

The bot stores the following data, per Discord server ("guild"):

- **Server ID** — the numeric Discord ID of the server, used to keep each server's game session separate.
- **Current game state** — the active prompt, the word it was generated from, and its solution count.

That is the complete list. The bot does **not** store:

- Usernames, user IDs, or any other user account information
- Message content or message history
- Direct messages
- Email addresses, IP addresses, or any personal information

## How Messages Are Processed

To run the game, the bot reads messages sent in channels whose topic contains the phrase "bomb party", in real time, solely to check whether a message solves the current prompt. Messages are processed in memory and immediately discarded. No message content is ever stored, logged, or shared.

## How We Use Data

Stored data is used only to operate the bot's game functionality. We do not use it for any other purpose. We do not sell, share, license, or transfer any data to third parties, advertisers, data brokers, or analytics services.

## Data Retention and Deletion

- Server data is deleted automatically when the bot is removed from a server.
- You may also request deletion of your server's data at any time by contacting us (see below). Requests are honored promptly.

## Children

The bot is intended for users aged 13 and over (or the minimum age of digital consent in your country), consistent with Discord's Terms of Service. We do not knowingly collect data from anyone under this age — and as described above, we do not collect personal data from anyone at all.

## Changes to This Policy

We may update this policy from time to time. The "Last updated" date at the top will reflect the latest revision. Continued use of the bot after changes take effect constitutes acceptance of the revised policy.
